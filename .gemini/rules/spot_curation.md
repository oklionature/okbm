# 백패킹 박지 데이터 큐레이션 및 팩트 검증 하드 룰 (절대 원칙)

AI는 백패킹 박지 JSON 데이터를 생성하기 전, 반드시 아래 체크리스트를 100% 수행하고 검증해야 한다.
추론이나 자의적인 수치/지명 날조(할루시네이션)가 발견될 경우 즉시 실패로 간주한다.

---

## 1. 체크리스트: 공원 구역(도립·군립·시립·국립) 명시 및 지자체 문의 의무
- [ ] **공원 구역 명시**:
  - 박지가 국립공원, 도립공원, 군립공원, 시립공원 등 '자연공원' 또는 지자체 관리 공원 구역에 속할 경우, **`desc_summary`의 `[뷰/특징]` 첫머리나 본문에 해당 공원 명칭(예: 도립공원, 군립공원 등)을 반드시 명확히 명시**한다.
- [ ] **지자체 사전 문의 안내 필수**:
  - 공원 구역일 경우, **"야영(백패킹) 가능 여부 및 현장 통제 규정에 대해 출발 전 해당 지자체(또는 공원관리사무소)에 반드시 사전 문의하고 확인해야 한다"**는 내용을 명시한다.

## 2. 체크리스트: 지리공간 위계 및 좌표-표고 일치성 검증
- [ ] **좌표와 표고의 실물 일치 검증**:
  - 카카오맵 핀 좌표의 실제 위치(들머리/암릉 초입/능선/주봉 정상)와 `elevation`(표고)의 대상 지점이 정확히 일치하는가?
  - 암릉 초입이나 중간 봉우리 좌표를 찍어놓고 주봉 정상의 해발고도를 붙이는 '좌표-표고 불일치' 왜곡을 절대 금지한다.
- [ ] **가공 지명/합성 명칭 생성 절대 금지**:
  - 공식 지도(카카오맵), 지자체 안내도, 언론 보도에 실재하지 않는 가상의 시설물 명칭(예: 'OO전망대 데크' 등)을 임의 합성해 지어내지 않는다.
- [ ] **등산로 진행 방향(순방향 vs 하산길) 역주행 왜곡 금지**:
  - 등산로의 지리적 흐름(들머리 -> 중간 경유지 -> 정상/박지 -> 하산길)을 검증하여, 하산 전용 코스나 하산 지점(옛 절터, 저수지 등)을 들머리 직등 최단 코스로 둔갑시키지 않는다.
- [ ] **거리 수치 자의적 조작 금지**:
  - 지자체 공식 코스 안내도나 실제 등산로 GPX 실측 거리에 없는 '임의 편도 거리'를 만들어내지 않는다.

## 3. 체크리스트: 좌표 및 들머리 (카카오맵 원천 데이터 직결)
- [ ] **추론/생성 절대 금지**: AI의 뇌나 기억 속 텍스트로 위도/경도, 지번 주소를 적지 않는다.
- [ ] **실제 카카오맵 API/스크립트 조회**: 카카오 로컬 검색 또는 지도 스크립트를 직접 실행하여 반환된 `x(경도)`, `y(위도)`, `address_name` 값을 복사-붙여넣기로 직결한다.
- [ ] **들머리 내비 검색 검증**: 들머리 명칭과 주소는 카카오내비/T맵에 실제 검색되는 장소명과 실제 지번/도로명 주소여야 한다.

## 4. 체크리스트: 본문 팩트 기반 작성 (수치/환경 날조 금지)
- [ ] **최소 3개 블로그/영상 교차 검증**: 최근 백패킹 후기 최소 3곳에서 실제 다녀온 팩트가 일치하는지 확인한다.
- [ ] **미확인 수치 추정 금지**: 텐트 동수, 주차 면수 등은 블로그 본문에 명시된 내용이 없으면 숫자를 지어내지 말고 "공간 협소" 또는 생략한다.
- [ ] **화기 관련 문구 제외**: 대한민국 산림 내 화기 사용 금지는 기본 전제이므로 본문에 화기 금지 언급을 일절 넣지 않는다.
- [ ] **편의시설 중복 금지**: 박지 자체의 식수/화장실 유무는 언급하지 않으며, 들머리 화장실 및 주차 여건만 1회 명확히 서술한다.
- [ ] **미확인 디테일(일몰 방향, 팩 종류 등) 날조 금지**: 블로그에 없는 내용을 일반화하여 적지 않는다.

## 5. 체크리스트: 문체 및 금지어 통제
- [ ] **감성 형용사/관광 홍보 문구 금지(Negative Constraints)**:
  - 금지어: "장엄한", "아름다운", "소금강", "파노라마", "비경", "황홀한", "환상적인", "압권" 등.
- [ ] **담담한 건조체/평어체 사용**:
  - 존댓말(~입니다, ~합니다)을 금지하고, 객관적 사실 위주의 단문 평어체(~다, ~함)로 기술한다.

## 6. 체크리스트: 미디어 URL (유연한 출처 허용)
- [ ] **출처 플랫폼**:
  - 기본적으로 `네이버 블로그`와 `유튜브`를 우선하되, 신뢰할 수 있는 `티스토리`, `지자체 공식 관광 안내`, `언론 기사` 링크도 자유롭게 포함 가능.
- [ ] **실제 접속 및 내용 일치 확인**:
  - 실제 해당 박지/코스를 직접 다룬 유효 URL(HTTP 200)인지 확인한다.

## 7. 체크리스트: 고정 스키마 및 분류값 준수
- [ ] **terrain (지형)**:
  - `데크`, `암릉`, `노지`, `계곡`, `섬`, `해변`, `동굴` 키워드를 기본으로 하되, **복합 지형인 경우 `암릉,노지`, `데크,암릉` 등의 콤마(,) 중복 표기 전면 허용**.
- [ ] **course_type (코스 형태)**: 반드시 다음 2개 중 택 1
  - `최단`, `편도`
- [ ] **droneStatus**:
  - 빈 문자열 `""` 허용 (필수 입력 아님). 필요한 경우에만 `ok`, `warn`, `no` 표기.
- [ ] **데이터 타입**:
  - `elevation`, `campsite_lat`, `campsite_lng`, `distance_km`, `difficulty` 등 모든 필드는 요청된 원본 JSON 템플릿의 문자열/숫자 타입을 엄격히 준수한다.
